# Login Page Test Checklist

Tested on: https://demoqa.com/login  
Browser: Chrome  
OS: Windows 10

## Functionality
- [ ] Login with valid credentials
- [ ] Login with invalid password
- [ ] Login with empty fields
- [ ] Login with invalid username format
- [ ] Password field is masked
- [ ] Forgot password link works
- [ ] Error messages are displayed correctly

## UI / UX
- [ ] All input fields visible and labeled
- [ ] Login button visible and clickable
- [ ] Error messages easy to read
- [ ] Password masking dots displayed correctly

## Security
- [ ] Password cannot be seen while typing
- [ ] Session expires after logout
- [ ] Login attempts limit (if applicable)
